**Wisk** is a Rust library for exact algebraic computations in physics, etc.  

**Wisk** is used in my related project [AUS](https://github.com/nonelop/AUS) as the main math library and is developed under its pressure. 

The library provides basic objects such as Matrix, Vector, Quaternion, and some methods for working with them, such as normalize or dot/cross.  

By the way, the name **Wisk** comes from the Dutch word Wiskunde (English Math).
